# EXPO-FT 在线训练命令

前提：服务器和本地环境按[安装命令](安装命令.md)准备好，并具有成功示教数据、SFT 权重及对应归一化统计。以下使用插槽任务和 2500 步权重的配置。

**执行顺序：服务器转换数据 → 服务器启动训练 → 本地启动机器人端。** 服务器负责模型推理和更新，本地负责机器人执行、采集与键盘接管；无需 NUC。

## 一、服务器执行

### 1. 激活服务器环境

```bash
cd ~/expo-ft
source expo-setup/activate.sh
```

服务器使用仓库根目录 `.venv`，下面的数据转换和训练命令在同一终端执行。

### 2. 转换成功示教数据

将 LeRobot 数据转换为 EXPO-FT 训练读取的 HDF5 格式，随机抽取 10 条成功示教：

```bash
python scripts/convert_lerobot_to_expo_ft.py \
  --dataset-root /home/suchenyu/.cache/huggingface/lerobot/scylearning/insert_black_rack_into_blue_slot_20260916_v01 \
  --output-dir ./data/online_rl/success \
  --mapping expo-setup/support/lerobot-ur5e-insert.json \
  --num-episodes 10 --seed 0 \
  --assume-success
```

`--num-episodes 10` 指定数量，`--seed 0` 固定抽样结果，`--assume-success` 表示这些示教均成功。输出为 `data/online_rl/success/原episode编号/traj.hdf5`，抽样信息保存在 `conversion.json`。

同一份数据和抽样配置只需转换一次；已有相同结果时复用目录。转换脚本不覆盖已有输出，重新抽样需换输出目录，并同步下一步的 `--dataset_path` 和 `--num_data`。

### 3. 启动在线训练

使用 2500 步全参 SFT 权重及配套归一化初始化，在线采用 LoRA 更新，Pi05 学习率为 `2.5e-5`：

```bash
WANDB_MODE=offline XLA_PYTHON_CLIENT_PREALLOCATE=false CUDA_VISIBLE_DEVICES=0,1,2,3 python train_pi_robo.py \
  --config_task=configs/task/ur_insert.py \
  --config=configs/model/expo_ft_ur_config.py \
  --config.pi05_weight_loader_path=./checkpoints/sft/ur_insert/2500/params \
  --config.pi05_assets_dir=./checkpoints/sft/ur_insert/2500/assets \
  --config.pi05_asset_id=scylearning/insert_black_rack_into_blue_slot_20260916_v01 \
  --dataset_path=./data/online_rl/success \
  --num_data=10 --seed=42 --batch_size=64 --utd_ratio=20 --max_steps=100000 \
  --update_type=episode --num_updates=3 --offline_ratio=0 \
  --replan_steps=8 --delay=0 --fsdp_devices=1 \
  --client_host=0.0.0.0 --client_port=8102 \
  --project_name=expo_ft_ur \
  --output_dir=./checkpoints/online_rl \
  --run_name=run_001 \
  --checkpoint_model --checkpoint_buffer \
  --checkpoint_interval=2000
```

核心配置：

- **数据与模型**：`--dataset_path` 指向转换结果，`--num_data=10` 读取 10 条示教；权重与归一化均来自 `checkpoints/sft/ur_insert/2500`。
- **训练与执行**：batch=64，UTD=20，步数上限及 replay 容量为 100000；模型预测 50 步、每次执行 8 步，上层动作频率 10 Hz。
- **运行环境**：`CUDA_VISIBLE_DEVICES=0,1,2,3` 使用四张 GPU；`fsdp_devices=1` 对应四卡数据并行，推理使用第一张可见 GPU，与同步训练共用。关闭 JAX 显存预分配，W&B 使用离线记录，无需登录。

服务器完成模型初始化后监听 **8102**。保持终端运行，再启动本地客户端。

模型 checkpoint 保存在 `checkpoints/online_rl/run_001/checkpoints/`，运行配置为 `checkpoints/online_rl/run_001/ur_run.json`，W&B 日志写入 `logs/wandb`。新实验更换 `--run_name`；恢复同一实验时保持原配置及运行名，在命令末尾追加 `--resume`。

## 二、本地机器人电脑执行

先核对本地 `configs/ur/insert.yaml` 中的机器人 IP、夹爪串口、相机序列号和复位位姿，然后启动客户端：

```bash
cd ~/expo-ft
source expo-setup/activate-client.sh
python -m client.run_client \
  --host=100.101.84.9 \
  --port=8102 \
  --config_task_path=configs/task/ur_insert.py
```

本地使用 `client/.venv`，连接服务器 **8102**，按服务器请求初始化 UR 和夹爪；无需复制模型权重或示教数据。`--host=100.101.84.9` 为服务器的 Tailscale 地址，两端须能通过 Tailscale 互通。

连接后按提示操作：**Enter 确认复位，复位后再按 Enter 开始；双击 Space 标记成功，双击 Enter 标记失败。** 运行中支持实体键盘接管，完整按键见[键盘与复位](support/UR迁移与运行.md#键盘与复位)。

若客户端持续提示连接失败，检查服务器是否已进入监听，以及地址和 8102 端口是否可达。软件与设备预检见[安装命令](安装命令.md#3-不连接机器人的软件检查)；独立评估见[评估命令](评估命令.md)。
